## 优先需要负责人澄清

1. **服务地区与用户类型**：公开的支持地区列表未列中国大陆，并称未列出的地区应联系支持；同一站点的“使用政策”称这些商业条款下的服务不适用于消费者 [S-011](来源索引.md#s-011)。这与项目目前面向中国大陆、普通用户学习使用的方向存在需要核实的适用范围问题；不能自行推断是否允许或提供规避方式。请负责人确认最新适用条款、服务地区和允许的客户类型。
2. **数据处理**：服务条款称不记录 API 请求内容、不会用于模型训练；“服务特定条款”又描述自愿参加开发合作伙伴模式时可用于训练，并提及数据保留设置和备份 [S-011](来源索引.md#s-011)。这些文字的适用关系、模式是否存在、默认设置、上游处理和保留期限需要负责人解释；官网声明不等于技术审计。
3. **条款质量与实际适用**：条款中提到不同服务、云托管和可用性目标，但部分措辞含占位示例邮箱或缺失地点 [S-011](来源索引.md#s-011)。不能把条款中提及的功能、云合作或 SLA 视作当前已提供或已获得授权；请提供经确认的正式条款及经营主体信息。
4. **真实费率和使用条件**：请提供模型、分组、币种、计价单位、倍率及折扣的具体解释，缓存／图片／长上下文费用、税费、余额充值、退款以及账单示例。公开页面的报价随时间变化，未实测扣费。
5. **接口与客户端**：请提供不同协议的准确 Base URL、路径、认证方式、模型 ID 与支持的软件版本；确认 Codex CLI、Claude Code、Cherry Studio 的配置截图、兼容范围及已知限制。

## 注册至首次调用：已观察与待核验的路径

**阅读版操作路线，尚不能作为已验证的完整教程。** 在符合服务地区、客户类型及条款的前提下：

1. 在 [官网](https://www.apophis.uk/) 查阅条款与 [模型广场](https://www.apophis.uk/model-plaza)；确认适用地区、模型组、接口、价格和预算。广场数据可能变化，别将渠道宣传或模型标识理解为上游授权证明。
2. 官网公开配置与前端路由显示存在 [注册入口](https://www.apophis.uk/register)，且配置为启用邮箱验证和上述三种邮箱后缀 [S-011](来源索引.md#s-011)、[S-013](来源索引.md#s-013)。实际页面字段、验证、是否需要其他条件、登录和注册成功均未操作验证。
3. 登录后，按平台实际说明查询可用额度、充值要求和退款规则。公开配置表明支付功能开启，但免费额度、支付方式、余额及实际费用未知；支付前确认价格和预算。
4. 根据官方控制台创建 API Key 并安全保存。前端路由有 `/keys`，但页面内容、创建步骤、权限、撤销方法与 Key 的实际用途未验证；勿将真实密钥提交仓库或发送给他人。
5. 向官方核实所选客户端及协议要求的 API 地址、具体路径、认证方式、可用模型 ID。站点配置给出的基础地址是 `https://www.apophis.uk`；这**不是对所有客户端可直接复制使用的配置保证**。
6. 在受信任客户端按经核实的配置输入地址、密钥、模型；查看是否有附加路径、协议、流式或工具调用要求。三个工具的实际版本与兼容性尚未验证。
7. 测试前确定明确授权、测试范围和预算；使用不含敏感信息的简短请求。收到有效模型回复，才能说明该账号、模型与协议在那次请求中成功；随后检查用量和费用，并按需撤销测试密钥。此步骤尚未执行。

常见阻碍包括验证邮件未送达、账号或地区限制、密钥无权限、模型 ID 不匹配、接口路径／协议错误、额度不足和限流；具体错误以官方支持为准。不要绕开平台限制。

## 新发现对研究与内容选题的影响

适合未来制作的内容包括：模型广场如何理解渠道、计费模式和上下文分档；注册和 Key 安全；API 地址、协议及模型 ID；用量与费用核对。公开教程发布前必须核准服务地区、用户类型、正式条款、真实界面和实际接入结果。优先解决适用性和隐私问题，再考虑面向用户的教程。
