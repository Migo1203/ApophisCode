# 竞品研究

状态：未开始。负责人指定的初期研究对象为 DMXAPI、AIHubMix、302.AI；它们的产品定位、功能、价格及与 ApophisCode 的可比性均待验证。其他直接竞品的选择待研究后提出，并由负责人确定范围。
