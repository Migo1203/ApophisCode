# 产品研究

状态：未开始。官网地址由项目负责人提供：[https://apophis.uk/](https://apophis.uk/)，本次未访问或核查。

## 待研究的问题

- 产品实际提供什么服务？公开资料如何描述其商业模式、服务边界及适用对象？
- 注册、创建 API Key、查找 Base URL 和模型名、发起首次请求、查看用量与费用各如何完成？
- 实际支持哪些模型、接口格式和能力？兼容条件、限制、版本和错误处理是什么？
- 价格、计费单位、支付方式、退款、服务支持与数据处理如何说明？
- Codex CLI、Claude Code、Cherry Studio 是否能接入？各自的版本、配置条件和可验证范围是什么？

负责人初步提及模型调用、Key 管理、模型广场、使用记录和费用统计；这些均是**用户提供、待验证**的信息，不能据此认定功能已存在。
