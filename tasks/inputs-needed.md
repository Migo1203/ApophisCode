# 下一阶段需要的产品资料

以下资料按优先级收集；没有的项目可标记「暂无」或「待确认」。不要在聊天或仓库提供真实 API Key、密码、访问令牌或客户个人信息；示例和截图请先脱敏。

## 优先：理解产品与首次使用路径

1. **官方资料入口：**除已提供的官网外，产品介绍、使用文档、API 文档、模型列表、价格页、服务条款、隐私政策及公告的公开链接；如无公开资料，可提供可分享的脱敏说明或截图。
2. **实际操作资料：**注册流程、控制台主要页面、API Key 管理、Base URL 和模型标识的获取方式、首次调用示例、用量和账单页面的脱敏截图或录屏说明；哪些步骤允许研究者查看也请注明。
3. **功能与限制：**已确认的模型和接口格式、版本、限额、支持能力、已知问题，以及 Codex CLI、Claude Code、Cherry Studio 是否有现成配置文档或测试记录；尚未确认的项目直接写明。
4. **计费与服务条件：**模型价格及单位、输入与输出计费、套餐或折扣、支付及退款规则、服务地区和支持渠道；注明适用日期和对象。
5. **测试边界：**是否允许操作测试账号或实际发起请求、可使用的环境、预算和责任人。仅在条件明确后，通过项目方认可的安全方式管理临时权限，不把凭据放进仓库。

## 后续定位和传播所需

6. **业务与授权信息：**对外可公开的经营主体、服务范围、已有授权或合作关系的可核验材料，以及需要进一步确认的问题；没有证据的合作关系不用于宣传。
7. **现有业务与渠道情况：**负责人已掌握的目标用户、地区、渠道账号、历史内容与聚合数据、现有推广限制；只提供脱敏和获准使用的资料，不提供客户名单或个人信息。
8. **决策约束：**项目目标、可投入人员与预算、既有品牌规范，以及需要负责人最终确认的决策边界。

资料本身也可能过时或存在冲突；研究时须记录来源、版本、日期和待核验项。
